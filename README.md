# UP Studio: Art & Booking

Create a premium bilingual (Persian-first, RTL) React Native Expo app called UP Studio. Use background #F7F6F3, Vazirmatn font, minimal luxury design. 5 tabs: Home (cinematic silent intro reel then embedded website https://upstudio.ct.ws), Gallery (intro reel with sound, 17 photos categorized: Fashion, Portrait, Sports, Fine Art; fullscreen shared element animation; save wallpaper on Android and iOS), Booking (WhatsApp reservation form), AI Assistant (placeholder wired for provided code), Contact (phone, email, WhatsApp, Telegram, Instagram, Google Maps using coordinates 35.6422050,51.2678540). Add skeleton loading, offline gallery cache, haptic feedback, push notification architecture, optional Dynamic Island/Live Activities hooks. The uploaded ZIP contains logo, reels, gallery, booking code and AI code—integrate them into the project.
